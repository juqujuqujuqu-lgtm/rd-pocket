# RD Pocket

Private Merkhilfe für den Rettungsdienst (Lahn-Dill-Kreis) als Web-App für das iPhone.

**Installieren:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Eigene Nummern, Schlüsselcodes und Einstellungen werden nur lokal auf dem Gerät gespeichert, nicht auf dem Server.

Kein Medizinprodukt. Alle Angaben ohne Gewähr – maßgeblich sind die SOPs und Vorgaben des ÄLRD.
